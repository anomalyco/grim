# Grim
*A place to think with your agents*

Grim is a collection of notes shared between you, your agents, and your team. Your agents write markdown in a shared filesystem that everyone can see.

All notes are:

* read & written by agents with normal bash commands in a virtual filesystem
* editable by humans with a nice markdown editor
* tracked in git so changes are easy to see

This allows workflows like this:

* an agent writes a plan to a file
* a human reads it and asks questions directly inside the content
* an agent reads the human's changes as a diff, and updates the file accordingly

Try it out! After setting up your first notebook, share it with your agent and get to work.
