# Grimoire
Type here: it's a **live** Markdown note. Try *italic*, ==highlight== or `code`.

Grimoire is a notepad for people and agents. Notes are live, multiplayer Markdown, stored as plain files in Git. Agents edit the same files through a shell, and you see their cursor as they write.

- Plain Markdown files, stored in Git
- Everyone sees edits and cursors as they happen
- [x] Write a note
- [ ] Hand it to an agent

> Edits are committed as you go.
